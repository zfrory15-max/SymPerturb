# Source and version note

This generated repository is based on the manuscript draft:

**SymPerturb converts symptom-network structure into testable intervention priorities**

Authors listed in the supplied draft: Zheng Zhu, Junwen Yu, Tiantian Hu, Zhongfang Yang, and Jiaqing Wang.

Repository scaffold date: **2026-08-31**.

The manuscript states that the numerical finite-sample VPPS results in the draft were produced using an earlier eight-component exploratory composite and must be regenerated under the revised seven-utility confirmatory definition. It also states that the software should be updated for symptom-specific anchors, separate location/scale maps, signed combination values, separate robustness diagnostics, and complete-pipeline bootstrap uncertainty before submission. This repository uses those revised requirements as its implementation target.

The bundled synthetic example is newly generated for smoke testing and is not the manuscript's reported 22-node simulation dataset.
