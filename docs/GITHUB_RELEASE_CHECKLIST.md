# GitHub release checklist

Before publishing this repository:

- [ ] Replace the placeholder `LICENSE` with the authors' chosen license(s).
- [ ] Confirm author names, affiliations, repository ownership, and citation metadata.
- [ ] Reconcile this reference implementation against the authors' original R/Python research code.
- [ ] Regenerate all confirmatory results using the revised seven-utility VPPS.
- [ ] Verify symptom-specific anchors and independent location/scale mappings in the publication analysis.
- [ ] Run the complete-pipeline bootstrap at the prespecified replicate count.
- [ ] Run the factorial misspecification/benchmark suite planned in the manuscript before making broad validation claims.
- [ ] Add DOI/persistent identifier and manuscript publication details when available.
- [ ] Check that no patient data, credentials, local paths, or private metadata are committed.
- [ ] Run `pytest` and the example CLI in a clean environment.
